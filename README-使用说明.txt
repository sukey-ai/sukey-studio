ROOM 2.0 — 角色观察屋（交互原型）

启动方式
1. 将 index.html 放到支持静态网站的托管服务（例如 GitHub Pages）。
2. 通过 https:// 网址打开。此版本使用 Three.js CDN，因此需要网络连接。
3. 在电脑或手机浏览器中均可操作；建议桌面端获得更好的 3D 观察体验。

当前已实现
- 3D 娃娃屋视角：旋转、缩放、点击房间与居民。
- 客厅、厨房、两间卧室的立体布局与家具。
- 居民创建、基础人格档案、心情/精力状态。
- 简单日常行为模拟、时间推进、事件记录。
- 多个独立世界存档、本地自动保存、JSON 导入/导出。
- 离开网页后再次打开时，根据离开时长进行有限补算。

重要说明
- 这是 ROOM 2.0 的可交互原型，不是已接入大语言模型的 AI 社会模拟器。
- 当前角色行为由浏览器内置规则随机模拟；不会真正理解复杂人格或自然聊天。
- 自动保存仅在当前浏览器/设备本地生效，不会自动跨设备同步。
- 网页关闭期间浏览器不会持续运行；重新打开时会做有限的离线补算。
- Three.js 通过 jsDelivr CDN 加载，首次打开需要网络。
- 若要实现真实 AI 人格、长期记忆、跨设备云存档和云端持续运行，需要后端服务、数据库及安全的 API 代理。
