ROOM 2.0 修复版

本次修复：
- 修正 Three.js 与 OrbitControls 的模块导入路径。原版没有配置模块映射，浏览器可能因此无法启动整个脚本，造成按钮无反应、3D 场景空白。
- 增加 WebGL 无法启动时的提示。

部署更新：
1. 解压本 ZIP。
2. 在 GitHub 仓库中打开原来的 index.html（如果中文翻译显示为“索引.html”，以文件实际名称为准）。
3. 选择编辑/删除旧文件，或直接通过“添加文件 → 上传文件”上传此 index.html 并确认替换。
4. 提交到 main 主分支。
5. 等待 GitHub Pages 自动重新部署，再刷新网站。iPhone Safari 可尝试关闭网页后重新打开，或用无痕标签页测试。

注意：
- 这是规则驱动的交互原型，不是真正接入大语言模型的 AI 社会模拟。
- Three.js 从 jsDelivr CDN 加载，需要联网。
- 存档保存在当前浏览器本地。
